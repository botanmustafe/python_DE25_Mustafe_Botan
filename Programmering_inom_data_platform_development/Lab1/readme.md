# Laboration 1 – Data Ingestion, Manipulation & Workflow

# Beskrivning
Programmet läser in "products.json" och transformerar datan med Pandas och flaggar dataproblem samt genererar en output.

# Funktionalitet
- Läser produktdata från fil
- Konverterar pris till nyttig affärsdata
- Flaggar
- Avvisar omöjliga värden
- Skapar analytics_summary.csv filen

## Körning
bash
python main.py
